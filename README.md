## Why this package?

`@stackline/types-nlcst` is the Stackline-maintained distribution of `@types/nlcst@1.0.4`. It is an independent continuation of [@types/nlcst](https://github.com/DefinitelyTyped/DefinitelyTyped); original authors and licenses remain credited below.

## Installation

```bash
npm install --save-dev @stackline/types-nlcst
```

Preserve existing imports and plugin resolution with an npm alias:

```bash
npm install --save-dev @types/nlcst@npm:@stackline/types-nlcst
```

Use the original `@types/*` alias for automatic TypeScript type discovery and existing `compilerOptions.types` settings. A scoped-only installation does not automatically expose the original type-package name.
